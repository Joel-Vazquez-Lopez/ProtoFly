# Spatial Embodiment

This document records the development and validation of ProtoFly's
spatial embodiment interface.

The aim is to connect activity generated by the connectome-constrained
brain to an explicit simulated body while keeping biological evidence
separate from simulation-level embodiment assumptions.

## 1. Spatial environment and body

ProtoFly currently contains a bounded continuous 2D environment with
spatial objects and independent fly body states.

Each `FlyBody` stores:

- x position
- y position
- orientation

Multiple flies therefore have independent physical states. The
environment does not contain a controller, goal policy, reward policy,
or hidden decision-making mechanism.

Basic locomotion mechanics support forward displacement and rotation,
with movement constrained by the environment boundary.

These commands are simulation-level embodiment primitives. They are
not treated as biological neural commands.

## 2. Biological steering interface

To connect the FAFB brain substrate to spatial behaviour, identified
descending neurons associated with steering during walking were added
to the biological neuron registry.

Current FlyWire FAFB v783 root IDs:

| Neuron | Root ID |
|---|---:|
| DNa01-R | 720575940644438551 |
| DNa01-L | 720575940627787609 |
| DNa02-R | 720575940604737708 |
| DNa02-L | 720575940629327659 |

All four neurons are present in the current 139,255-neuron ProtoFly
substrate.

DNa02 is used as the initial steering readout.

The readout preserves bilateral neural activity rather than assigning
either neuron a symbolic `TURN_LEFT` or `TURN_RIGHT` command.

ProtoFly defines:

    steering_drive = DNa02_L_rate - DNa02_R_rate

Positive values correspond to counter-clockwise/left rotation in the
simulation coordinate convention, while negative values correspond to
clockwise/right rotation.

The readout remains measured in Hz. It is not itself an angular
velocity.

Conversion from this neural signal to simulated angular displacement
requires an explicit steering gain. That gain is an embodiment-model
parameter and is not currently treated as a biologically measured
calibration.

## 3. Whole-brain DNa02 propagation test

Experiment:

    experiments/01_single_fly/07_dna02_steering_readout.py

The previously validated sugar sensory perturbation was reused as a
controlled input to the current whole-brain model.

The stimulation uses the established FlyWire labellar sugar-GRN
population:

- 21 reference GRNs
- 20/21 present in current FAFB v783
- 100 Hz Poisson stimulation
- 1 second duration

The stimulus propagates through the full current 139,255-neuron
connectome model. DNa01 and DNa02 are observed without applying any
body movement.

No-sugar condition:

    Active neurons: 0
    Total spikes:   0

    DNa01_R: 0
    DNa01_L: 0
    DNa02_R: 0
    DNa02_L: 0

Sugar-stimulation condition, seed 42:

    Active neurons: 761
    Total spikes:   25,728

    DNa01_R:  0
    DNa01_L:  8
    DNa02_R:  0
    DNa02_L: 79

This produced:

    DNa02_L - DNa02_R = +79 Hz

Thus activity originating from identified sensory neurons can propagate
through the current whole-brain substrate and reach identified
descending neurons associated with steering.

This result does not by itself demonstrate steering behaviour.

## 4. DNa02 reproducibility

Experiment:

    experiments/01_single_fly/08_dna02_steering_trials.py

The same 100 Hz sensory perturbation was repeated for 10 trials while
restoring the same initial network state before every trial and changing
the Poisson seed.

Results:

    DNa02_L = 82.90 ± 7.64 spikes/s
    DNa02_R =  0.80 ± 2.20 spikes/s
    L - R   = +82.10 ± 6.57 spikes/s

    Left-dominant trials:  10/10
    Right-dominant trials: 0/10
    Balanced trials:       0/10

The strong bilateral asymmetry is therefore reproducible across the
tested Poisson realizations rather than being specific to the original
seed.

One trial also entered a substantially higher global-activity regime:

    Trial 9:
    Active neurons: 3,313
    Total spikes:   56,202

Despite this change in global activity, the DNa02 response remained
left-dominant:

    DNa02_L = 96
    DNa02_R = 7

This observation should be considered alongside the previously
documented sensitivity of the current network dynamics.

## 5. Sensory laterality limitation

The sugar-GRN population used here originates from the established
unilateral labellar sugar-sensory stimulation paradigm used for the
whole-brain model validation.

Consequently, the strongly asymmetric DNa02 response must not currently
be interpreted as evidence that ProtoFly turns toward sugar.

The experiment establishes:

    identified sensory neurons
        ->
    whole-brain connectome dynamics
        ->
    identified steering-related descending neurons

It does not yet establish:

    spatial sugar position
        ->
    directional sensory evidence
        ->
    appropriate steering
        ->
    movement toward sugar

A rigorous spatial steering experiment will require defensible
left/right sensory populations or another biologically grounded
directional sensory interface.

Contralateral sensory neurons must not be invented merely to obtain a
symmetric experimental design.

## 6. Current status

Established:

- independent spatial body state
- bounded 2D environment
- simulation-level locomotion mechanics
- identified biological steering-related descending neurons
- bilateral DNa02 neural readout
- explicit neural-to-embodiment steering interface
- propagation from identified sensory neurons through the whole-brain
  substrate to DNa02
- reproducible DNa02 asymmetry under the tested unilateral sensory input

Not yet established:

- biologically grounded forward locomotor drive
- directional spatial sensory input
- appropriate turning toward or away from environmental objects
- closed spatial sensorimotor behaviour
- calibrated relationship between DNa02 firing and simulated angular
  velocity
- autonomous navigation

These distinctions should be preserved as spatial embodiment is
developed further.
